# SLIIT Courseweb Module Cleaner

A browser script designed to clean up the SLIIT Moodle (Courseweb) interface. It automatically hides assignment links, quizzes, and modules meant for other centers (Kurunegala, Metro, Northern Uni, Kandy) or Weekday groups, while safely keeping your specific Weekend group links and important shared notices visible.

## Features
* **Declutters your view:** Hides irrelevant activities and links.
* **Keeps Section Titles:** Maintains the structure of the page.
* **Notice Protector:** Ensures you never miss an important rescheduled lab or general announcement.

## How to Install (1-Click)
1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for your browser.
2. [Click here to install the script](https://github.com/dulithdivisekara/sliit-courseweb-cleaner/raw/refs/heads/main/sliit-courseweb-cleaner.user.js).
3. Click **Install** when the Tampermonkey tab opens.
4. Refresh Courseweb!
