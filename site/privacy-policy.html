Privacy Policy

SLIIT Courseweb Cleaner • Last Updated: October 2026

The SLIIT Courseweb Cleaner browser extension is developed with a strict "Privacy First" methodology. We respect your privacy and are committed to full transparency regarding how the extension operates.

1. Zero Personal Data Collection

We do not collect, transmit, distribute, sell, or monetize any of your personal data. The extension operates entirely within the confines of your local browser environment:

  • User Preferences: Your selected campus, batch, custom keywords, ghost mode, and dark mode toggles are stored locally using the native browser APIs (chrome.storage.sync and chrome.storage.local). When Chrome Sync / Edge Sync is enabled, your browser may securely synchronize these preferences across your own signed-in devices. This data is never sent to any external server maintained by us.
  • Courseweb Data & Text Processing: The extension inspects the text of the courseweb.sliit.lk web pages strictly via local client-side scripts to identify which elements to filter or dim. No student names, grades, course IDs, or LMS tokens are ever stored, captured, or transmitted.

2. Remote Network Communication

The extension makes a single, periodic outbound network request (scheduled once every 24 hours via chrome.alarms) to download the latest community-contributed filtering rules:

https://raw.githubusercontent.com/dulithdivisekara/sliit-courseweb-cleaner/main/rules.json

This request is a standard, anonymous HTTP GET request to download a static open-source JSON file. It transmits no tracking identifiers, telemetry, or user credentials.

3. Third-Party Libraries & Remote Code

The extension includes an embedded copy of the open-source Dark Reader engine (MIT License) packaged locally to generate high-contrast styles. The extension executes zero remote executable code (no eval(), no dynamic scripts, no external JavaScript downloads).

If you have any questions, feedback, or verification requests regarding this Privacy Policy or the security of the extension, you are welcome to inspect the source code or reach out directly:
