## Community Heuristic Rules (`rules.json`)

Because lecturers across SLIIT's faculties and regional centers periodically introduce new naming conventions for cohorts, partner universities, or universal announcements, **SLIIT Courseweb Module Cleaner** decouples its dynamic keyword dictionaries into [`rules.json`](https://github.com/dulithdivisekara/sliit-courseweb-cleaner/blob/main/rules.json) at the root of the repository.

When a pull request updating `rules.json` is merged into the `main` branch, every installed browser extension automatically pulls the updated rules within 24 hours via the background service worker alarm (`fetchRulesAlarm`).

### `rules.json` Schema Specification

```json
{
  "version": "1.2",
  "ignoreKeywords": [
    "notice",
    "rescheduled",
    "general",
    "announcement",
    "important",
    "exam",
    "timetable",
    "guideline",
    "final exam",
    "mid exam",
    "repeat",
    "prorata"
  ],
  "campusAliases": {
    "Malabe": ["malabe", "mlb"],
    "Metro": ["metro", "metropolitan", "colombo"],
    "Matara": ["matara", "mathara", "mtr"],
    "Kandy": ["kandy", "kdy", "kandy uni"],
    "Kurunegala": ["kurunegala", "kurunegale", "kurunagala", "krn"],
    "Jaffna": ["jaffna", "northern", "nothern", "northern uni", "jfn", "nu"]
  },
  "partnerKeywords": [
    "curtin",
    "deakin"
  ]
}
```

| Property | Type | Technical Purpose |
| :--- | :--- | :--- |
| `version` | `string` | Semantic revision identifier for the community rule dictionary. |
| `ignoreKeywords` | `string[]` | Lowercase tokens that trigger the Notice Protector when evaluating general announcements. |
| `campusAliases` | `Record<string, string[]>` | Maps canonical campus identifiers (`Malabe`, `Metro`, `Matara`, `Kandy`, `Kurunegala`, `Jaffna`) to lowercase substring/word aliases. |
| `partnerKeywords` | `string[]` | Lowercase identifiers for international partner university streams (`curtin`, `deakin`). |

## Build & Compilation Pipeline (`build.sh`)

Executing `./build.sh` (or `npm run build`) performs a deterministic 5-step build:

1. **Extension Asset Sync**: Copies `src/shared-core.js`, `src/extension-main.js`, `src/darkreader.js`, `src/popup.*`, and `src/shared-styles.css` (mapped to `extension/styles.css`) into `extension/`.
2. **Chromium Package Assembly**: Strips any temporary swap files and packages `extension/` (using `manifest.json`) into `dist/sliit-courseweb-cleaner-extension.zip`.
3. **Firefox AMO Package Assembly**: Swaps `extension/manifest.firefox.json` in as `manifest.json` (preserving `browser_specific_settings.gecko.id`), builds `dist/sliit-courseweb-cleaner-firefox.zip`, and restores the Chromium `manifest.json`.
4. **Userscript Single-File Compilation**: Concatenates the `@UserScript` metadata header, `src/shared-styles.css` (injected via `GM_addStyle`), `src/shared-core.js`, and `src/userscript-main.js` into `dist/sliit-courseweb-cleaner.user.js`.
5. **Integrity Check**: Verifies all output archives and reports artifact sizes.

```bash
# Run full multi-target compilation
./build.sh
```

## Verification & Testing Workflow

### 1. Syntax & Bundle Integrity Check

Run the zero-dependency Node.js syntax verification suite across all source scripts, service workers, and compiled userscript bundles:

```bash
npm test
```

What `npm test` validates:
- `node --check src/shared-core.js`
- `node --check src/extension-main.js`
- `node --check src/userscript-main.js`
- `node --check src/popup.js`
- `node --check extension/service-worker.js`
- `node --check dist/sliit-courseweb-cleaner.user.js`
- JSON schema validation of `rules.json`, `extension/manifest.json`, and `extension/manifest.firefox.json`.

## Submitting a Pull Request

1. Fork the repository and create a descriptive feature or bugfix branch (`git checkout -b fix/kandy-batch-heuristic`).
2. Modify the canonical source files in `src/` or `rules.json`.
3. Run `./build.sh && npm test` to regenerate `extension/` and `dist/` and verify zero syntax errors.
4. Commit your changes using Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`) and open a Pull Request against `main`.
